A make.fun entry for **Make the AI Judge Laugh: Cat Reviews Its Human** ($2).

## The entry

One deadpan one-star review written by a house cat about its human:

> One star. I sat on his keyboard to help with his deadline; he moved me off, finished it himself, and still expects a cuddle.

124 characters — inside the 1–200 character gate, single line, specific complaint (the laptop keyboard), feline voice, sting in the last words.

## How it works

`main.py` (Python 3.13, standard library only) writes the review to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), then
reads it back and verifies the text byte-for-byte and the 1–200
character gate.

## Run

```sh
python3 main.py
```
